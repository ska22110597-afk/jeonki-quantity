## 자재 수량 할증 (비고란 근거)
- 통신: 표준품셈 1-1-6 표 적용 — 옥내 케이블 7.5%, 옥내 전선관 10%, 트레이·덕트 5%, 옥외 케이블·합성수지관·직매 3%.
- 전기: 전기공사 표준품셈 1-6(2026판 PDF 44쪽에서 직접 확인) — 옥내전선 10, 옥외전선 5, 케이블 옥내 5·옥외 3, 전선관 옥내 10·옥외 5, 트레이·덕트 5, 파형전선관 3.
- 부속품률: 통신 3-1-2 에 따라 박강·후강·합성수지·가요 20%, CD·PF 40%. 전기는 15%(CD 40%).
- 근거는 일위대가 자재 행 비고에 `통신 3-1-1 · 통신 1-1-6 옥내 전선관 자재할증 10%` 형태로 기입. 지중·노출 장소 품 할증은 첫 인부 행 비고에 기입.

## 이어서 내역서 만들기
- 일위대가목록까지 저장한 파일을 다시 넣으면 일위대가를 새로 만들지 않고 읽어서 내역서만 만든다.

## 오류 대처 기능 (v1.0 이후)
- 품셈 미매칭: 표의 「품셈」 열에 빨간 `미매칭`, [미매칭만 보기], [선택 품목 품셈 연결](데이터베이스/품셈_연결목록.json 에 저장), 결과 파일 `점검목록` 시트.
- 적용 규격 비고: 이하·이상 구간이나 다른 규격 품을 쓰면 첫 인부 줄 비고에 `적용 규격 …`.
- 엑셀이 열려 있어 저장이 막히면 `_2`, `_3` 이름으로 자동 저장.
- 불러온 일위대가 파일의 구조 문제(합계 줄 없음 등)를 알리고 인식된 호표만으로 계속할지 묻는다.
- 단가대비표 양식을 못 읽으면 열 지정 창 → 변환 파일(데이터베이스 폴더) 생성.
- 내장 품셈 버전(`PUMSAM_DB_VERSION`)이 바뀌면 옛 사용자 DB 는 백업 폴더로 옮기고 새 파일로 갱신.
- 담은 공정은 `임시저장.json` 에 자동 저장되어 다시 열면 복구를 묻는다. 저장 성공 시 삭제.
- 문자로 적힌 수량·단가(`1,200㎡`, `약 3`)는 숫자로 정리하고 로그에 남긴다.
- 같은 품명·규격 중복은 목록에 `중복` 표시, 숨길지 묻고 `점검목록`에 기록.
