# 자동 내역서식 프로그램

전기공사 견적용 **PyQt6 데스크톱 앱**입니다.  
원본 엑셀은 읽기만 하고, 결과는 최종 산출에 맞춰 `일위대가목록_결과_` · `단가대비표_결과_` · `공량산출_결과_` + 날짜시간.xlsx 새 파일로만 저장합니다.

현재 판: **V.1.0.0** (첫 배포)

## 창 구성

- 맨 위 검은 표제에 **자동 내역서식 프로그램 V.1.0.0** 이 적혀 있습니다. 흰색 윈도우 막대 대신 검정·흰색 빗금 무늬입니다.
- 금은 바탕 제목 아래 왼쪽에 제작자·문의, 오른쪽에 무단 복제 금지를 둡니다.
- **전기 / 통신** 버튼으로 표준품셈 파트를 고릅니다. 안내 글은 `현재 선택된 적용 품셈 : 전기_표준품셈.xlsx` 형식입니다.
- **왼쪽 (정방향)**  
  단가대비표 한 칸입니다. 놓으면 단가대비표부터 일위대가목록까지 작성합니다.
- **오른쪽 (역방향)**  
  일위대가목록 한 칸입니다. 놓으면 단가대비표까지 작성합니다.
- **아래 (공량산출)**  
  일위대가목록 시트가 있는 엑셀을 놓으면 공량산출서를 만듭니다.
- 세 칸 안내 글은 모두 `여기를 눌러 파일을 선택하거나, 파일을 끌어다가 놓아주세요.` 입니다.
- **결과 저장 폴더**에서 저장 위치를 고르고, 확인란을 체크한 뒤 **산출 및 저장**을 누릅니다. 산출이 시작되면 버튼이 **작업 중 — 누르지 마세요**로 바뀌고, 완료 창과 같은 무늬의 **작업 중** 창에 게이지가 끝까지 채워집니다. 끝날 때까지 버튼을 다시 누를 수 없습니다.
- **새로고침**은 선택한 파일을 모두 비워, 프로그램을 처음 켠 상태로 되돌립니다.

기본 저장 후보는 `C:\전기공사_공량산출_결과` 입니다. OneDrive 폴더는 가능하면 피하세요.

## 넣는 파일

| 칸 | 양식 |
| --- | --- |
| 단가대비표 | 품명·규격·단위·물가정보·PAGE·조달청. **코드 열은 쓰지 않습니다.** 수량 칸은 없어도 됩니다. |
| 일위대가목록 | 명칭·규격·단위. 프로그램이 정방향에서 작성. 공량산출 칸에도 이 시트가 있는 파일을 놓습니다 |

단가대비표에 수량이 없으면 일위대가목록 수량도 비워 둡니다. 단위 글자(M, 개 등)를 수량에 넣지 않습니다.

테스트용 단가대비표는 저장소 `samples/단가대비표_샘플.xlsx` 에 있습니다. GitHub에서 그 파일을 눌러 Download 하면 됩니다.

정방향 단가대비표는 원본 서식을 복사하지 않고 프로그램 양식으로 다시 씁니다. 같은 품명이어도 행을 나누어 쓰고, 물가정보 옆 PAGE와 조달청 금액은 그대로 옮깁니다.

## 결과 엑셀

글자체는 **굴림**입니다. 단가대비표·일위대가·일위대가목록은 행 높이 30, 제목은 1~2행 병합·가운데·밑줄입니다.  
**단가는 소수 2자리, 금액은 소수 1자리**로 표시합니다.

| 시트 | 내용 |
| --- | --- |
| 단가대비표 | 코드 열 없음. 품명·규격·단위·물가정보·PAGE(열너비 5)·조달청·적용단가 |
| 일위대가 | 호표. 품명 + 품셈 인부 + 합계. 인부 **수량(품)은 비워 두고** 단가·금액 수식만 넣습니다. 합계는 **금액**만 합산(단가 열은 비움). 호표 제목은 왼쪽 맞춤. 비고에 `전기 5-1` |
| 일위대가목록 | 단가=일위대가 합계 **금액**, 금액=단가×수량. 합계 단가=`TRUNC(재료+노무+경비 단가,2)`, 합계 금액=`TRUNC(재료+노무+경비 금액,1)`. 아래쪽에 부속재·잡자재·노무비·공구손료 통합 양식 |
| 공량산출서 | 일위대가목록 행을 그대로 표시. 품셈·인부명칭은 **일위대가 호표**에서 가져옵니다. 공량=`산출수량 × 품셈 × (할증%/100)`. 공량산출 직전에 호표를 1, 2, 3… 순서로 다시 붙입니다 |
| 품셈표 | 데이터베이스와 같은 검색 양식(키워드·명칭·규격·단위·노무명칭·품셈·할증%·품셈근거). 품셈근거는 1장부터 10장 숫자 순. 공량산출 양식으로 바꾸지 않습니다. 같은 명칭·규격의 다음 인부는 키워드·명칭만 비움 |
| 노임단가 | 1~2행 제목 병합. 직종·노임단가 열너비 17, 비고 40, 행 높이 25, 금액은 천 단위 구분 |

일위대가 규칙:

- 호표에는 품명(자재)과 표준품셈 인부, 합계만 넣습니다. 부속품비·잡재료비·공구손료는 호표에 만들지 않습니다.
- 표준품셈에서 인부 종류가 맞으면 그 인부 행만 넣습니다. **품 숫자(수량)는 넣지 않습니다.** 노임 VLOOKUP, 금액=`단가×수량`, 합계 수식은 그대로 둡니다. 품은 엑셀에서 직접 확인하고 묶어서 채웁니다.
- 일위대가목록 맨 아래에 전체 통합 양식으로 CD 전선관 40%, 전선관 15%, 전선·전선관 2%, 직종별 노무비, 직접노무비 3% 공구손료를 수식으로 넣습니다.
- 표준품셈에 인부가 여러 명이면 호표에 모두 넣습니다.
- 딱 맞는 규격이 없고 「6㎟ 이하」처럼 이하 구간만 있으면, 품목 규격 이상인 가장 작은 이하 구간을 씁니다. 예: 4㎟ → 6㎟ 이하, 3㎟ → 3㎟ 이하.
- 같은 명칭이면 아연도 16 mm 와 16 mm / G 16 mm 처럼 앞말만 다른 규격도 같은 크기로 맞춥니다. 후강전선관 = 강제전선관, HI관 = 경질비닐전선관처럼 현장에서 같은 품으로 쓰는 이름도 묶어둡니다. 1C/3C처럼 다른 말은 끌어오지 않습니다. 단가대비표의 `_노출`/`_지중`/`_직매` 는 품셈표에 줄을 나누지 않고, 원표 품을 찾은 뒤 할증만 붙입니다.
- 품셈표의 품셈 칸은 표준품셈 원표 숫자(할증을 곱하기 전)입니다. 할증은 할증% 칸에 따로 적습니다. 같은 규격을 매입·노출·지중 세 줄로 나누지 않습니다. 일위대가 인부 규격은 `일반공사 직종` 만 적습니다. 일위대가 비고에는 `전기 5-1` 같은 적용품만 적습니다.
- 공량산출서를 만들 때 일위대가 호표 번호만 시트 위에서부터 다시 1, 2, 3…으로 붙입니다. 수동으로 호표를 끼워 넣어도 번호만 고칩니다.
- 공량산출서 품셈은 품셈표가 아니라 그 품목 일위대가 인부 수량 칸을 봅니다. 인부가 여러 명이면 수량을 더합니다. 공량산출서 할증% 는 단가대비표 명칭의 `_노출`(120) · `_지중`(70) · `_직매`(80) 를 반영합니다.
- 표준품셈에 그 품목이 없으면 전기는 **내선전공 1명**, 통신은 **통신내선공 1명**만 넣습니다. 지중/노출처럼 비슷한 이름은 끌어오지 않습니다.

## 표준품셈 · 노임단가

프로그램 `data` 폴더의 씨앗 파일이 exe에 같이 실립니다. 처음 산출하면 저장 폴더에 복사본이 생깁니다.

`C:\전기공사_공량산출_결과\데이터베이스\전기_표준품셈.xlsx`  
`C:\전기공사_공량산출_결과\데이터베이스\통신_표준품셈.xlsx`  
`C:\전기공사_공량산출_결과\데이터베이스\노임단가.xlsx`

창에서 **전기**를 누르면 전기 파일만, **통신**을 누르면 통신 파일만 읽습니다. 같은 자재라도 전공·품셈은 파일마다 따로 적습니다. 전기자재의 품셈근거는 통신 파일에서도 `전기 5-1`처럼 둘 수 있습니다.

이 복사본을 고치면 다음 산출부터 반영됩니다. 노임은 대한건설협회 **2026년 하반기 시중노임**을 넣어 두었습니다.

전기 표준품셈은 대한전기협회 전기공사 표준품셈 **전문**(1장 적용기준, 2장 송전, 3장 변전, 4장 배전, 5장 내선, 6장 계측·자동제어, 7장 전기철도)을 프로그램이 붙일 수 있게 풀어 둔 베이스입니다. 통신 표준품셈은 한국정보통신산업연구원 **정보통신공사 표준품셈**(2~13장)을 같은 방식으로 풀어 두었습니다. 5장 내선·3장 구내배관은 단가대비표 명칭(_노출/_매입/_지중, HI 규격)에 맞게 따로 풀어 두었습니다.

엑셀 표준품셈 파일은 1행 이름을 **키워드**로 두고, 행 높이 20, 글자체 굴림, 1행만 하늘색·가운데, 아래 칸은 흰 바탕입니다. 키워드·규격의 제곱 밀리미터는 `㎟` 로 통일합니다. 규격의 `〃` 는 위와 같음으로 풀어 `㎟ 이하` 까지 이어 받고, 품셈 `-` 는 빈 인부로 읽습니다. 같은 명칭·규격에 인부가 여러 명이면 아래 칸의 키워드·명칭만 비우고 **규격은 비우지 않습니다.** 인부 행은 지우지 않습니다. 단위 열 너비는 9.38 입니다.

- 접미사 없는 명칭 = 콘크리트 **매입** (할증 100%) — 내선 배관
- `_노출` = 철근콘크리트 노출 (할증 120%)
- `_지중` = 지중 배관 (할증 70%)
- 전선관·박스·등기구 인부는 **내선전공**, 전력·제어 케이블은 **저압케이블전공**, 전주·가선은 **배전전공+보통인부**, 변압기·배전반은 **변전전공** 등 표에 적힌 직종

파일 안에 `적용기준` · `공종별인부` 시트도 있습니다.

**V.1.0.0:** 첫 배포입니다. 품셈표에는 원표 품값만 두고, 노출·매입·지중 할증 행은 같은 규격을 세 줄로 나누지 않습니다. 단가대비표 명칭 끝 `_노출`/`_지중`/`_직매` 는 찾을 때 할증만 붙이며, 일위대가·공량산출서에도 같은 원표 품셈을 씁니다. CD관 80%처럼 원표 해설에 적힌 숫자는 그대로 둡니다. 창 맨 위는 검정·흰색 빗금 표제이고, 제목은 `자동 내역서식 프로그램 V.1.0.0` 입니다. 정방향·역방향은 드롭 칸을 하나씩만 둡니다. 작업 중 게이지는 92%에서 멈추지 않고 끝까지 채웁니다. 이미 만들어 둔 `전기_표준품셈.xlsx` · `통신_표준품셈.xlsx` 는 **지운 뒤** 다시 산출해야 원표 한 줄 품셈이 들어갑니다. (프로그램이 기존 큰 파일을 덮어쓰지 않습니다.) 노임단가 파일은 산출할 때 열너비·천 단위 서식이 다시 맞춰집니다.

예전에 만든 아주 작은 `전기_표준품셈.xlsx` 씨앗만 다음 산출 때 새 베이스로 바뀝니다.

## 실행 (개발 PC)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

테스트:

```bash
python -m pytest
```
