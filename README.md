# 제작자_박남석 자동 내역서식 프로그램

전기공사 견적용 **PyQt6 데스크톱 앱**입니다.  
원본 엑셀은 읽기만 하고, 결과는 `공량산출_결과_날짜시간.xlsx` 새 파일로만 저장합니다.

현재 판: **v1.1**

## 창 구성

- **왼쪽 (정방향, 푸른색)**  
  단가대비표를 놓으면 일위대가 → 내역서 → 공량산출서까지 만듭니다. 일위대가는 선택입니다.
- **오른쪽 (역방향, 붉은색)**  
  내역서를 놓으면 단가대비표와 공량산출서를 만듭니다.
- 아래 **결과 저장 폴더**에서 저장 위치를 고르고, 확인란을 체크한 뒤 **산출 및 저장**을 누릅니다.

기본 저장 후보는 `C:\전기공사_공량산출_결과` 입니다. OneDrive 폴더는 가능하면 피하세요.

## 넣는 파일

| 칸 | 양식 |
| --- | --- |
| 단가대비표 | 샘플과 같이 품명·규격·단위·재료비(물가정보/적용단가). **수량 칸은 없어도 됩니다.** |
| 일위대가 | 선택. 이미 만든 호표가 있을 때만 |
| 내역서 | 명칭·규격·단위·재료비 단가가 있는 내역서 |

단가대비표에 수량이 없으면 내역서 수량도 비워 둡니다. 단위 글자(M, 개 등)를 수량에 넣지 않습니다.

## 결과 엑셀

글자체는 **굴림**입니다. 행 높이 20, 바탕 흰색, 자동 줄 바꿈 없음.

| 시트 | 내용 |
| --- | --- |
| 단가대비표 | 정방향: 넣은 표. 역방향: 내역서에서 만든 표(코드 칸은 비움) |
| 일위대가 | 호표. 제목에 품셈근거를 쓰지 않고, **비고**에 `전기 5-1`처럼 적습니다 |
| 내역서 | 일위대가 단가와 연결. 수량은 단가대비표에 있을 때만 |
| 공량산출서 | 공량산출 명칭 칸에 내선전공·보통인부 등 직종을 적습니다 |
| 품셈표 | 표준품셈 복사 |
| 노임단가 | 2026년 하반기 시중노임 (2026.9.1 적용) |

일위대가 규칙:

- 전선관: 자재 + 전선관부속품비 15% + 잡재료비 2% + 품셈 인부 + 공구손료 3%
- 케이블/전선: 자재 + 잡재료비 2% + 품셈 인부 + 공구손료 3%
- 그 외: 자재 + 품셈 인부 + 공구손료 3%
- 표준품셈에 인부가 여러 명이면 호표에 모두 넣습니다.

## 표준품셈 · 노임단가

프로그램 `data` 폴더의 씨앗 파일이 exe에 같이 실립니다. 처음 산출하면 저장 폴더에 복사본이 생깁니다.

`C:\전기공사_공량산출_결과\데이터베이스\표준품셈.xlsx`  
`C:\전기공사_공량산출_결과\데이터베이스\노임단가.xlsx`

이 복사본을 고치면 다음 산출부터 반영됩니다. 노임은 대한건설협회 **2026년 하반기 시중노임**을 넣어 두었습니다.

## 실행 (개발 PC)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

테스트:

```bash
python -m pytest
```

## 사무용 PC용 exe

Windows에서 `build_exe.bat` 을 실행하거나, GitHub **Actions → Build Windows EXE → Run workflow** 후 Artifacts 의 `jeonki-quantity-exe` 에서 `GongryangCalc.exe` 를 받습니다.
