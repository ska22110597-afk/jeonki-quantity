# 제작자_박남석 자동 내역서식 프로그램

전기공사 견적용 **PyQt6 데스크톱 앱**입니다.  
원본 엑셀은 읽기만 하고, 결과는 `공량산출_결과_날짜시간.xlsx` 새 파일로만 저장합니다.

현재 판: **v1.4**

## 창 구성

- **전기 / 통신** 버튼으로 표준품셈 파트를 고릅니다. 고른 파트의 파일만 불러옵니다.
- **왼쪽 (정방향, 푸른색) — 투입 3칸**  
  단가대비표, 일위대가, 내역서를 넣을 수 있습니다. **최종 산출은 내역서**입니다.
- **오른쪽 (역방향, 붉은색) — 투입 2칸**  
  내역서, 일위대가를 넣을 수 있습니다. **최종 산출은 단가대비표**입니다.
- **아래 (공량산출, 녹색)**  
  `1. 전열설비공사`처럼 파트를 나눈 내역서를 놓으면 **파트 구분 그대로 공량산출서**를 만듭니다.
- **결과 저장 폴더**에서 저장 위치를 고르고, 확인란을 체크한 뒤 **산출 및 저장**을 누릅니다.

기본 저장 후보는 `C:\전기공사_공량산출_결과` 입니다. OneDrive 폴더는 가능하면 피하세요.

## 넣는 파일

| 칸 | 양식 |
| --- | --- |
| 단가대비표 | 품명·규격·단위·물가정보·PAGE·조달청. **코드 열은 쓰지 않습니다.** 수량 칸은 없어도 됩니다. |
| 일위대가 | 이미 만든 호표가 있을 때 |
| 내역서 | 명칭·규격·단위. 공량산출용은 파트 제목 행(`1. 전기공사`)을 넣어 주세요. |

단가대비표에 수량이 없으면 내역서 수량도 비워 둡니다. 단위 글자(M, 개 등)를 수량에 넣지 않습니다.

정방향 단가대비표는 원본 서식을 복사하지 않고 프로그램 양식으로 다시 씁니다. 같은 품명이어도 행을 나누어 쓰고, 물가정보 옆 PAGE와 조달청 금액은 그대로 옮깁니다.

## 결과 엑셀

글자체는 **굴림**입니다. 단가대비표·일위대가·내역서는 행 높이 30, 제목은 1~2행 병합·가운데·밑줄입니다.  
**단가는 소수 2자리, 금액은 소수 1자리**로 표시합니다.

| 시트 | 내용 |
| --- | --- |
| 단가대비표 | 코드 열 없음. 품명·규격·단위·물가정보·PAGE·조달청·적용단가 |
| 일위대가 | 호표. 단가=금액/수량, 부속품·잡재료·공구손료도 수식으로 채움. 비고에 `전기 5-1` |
| 내역서 | 일위대가 합계 **금액**만 연결. 단가 열은 비움 |
| 공량산출서 | 내역서 파트 구분을 그대로 표시 |
| 품셈표 | 1~2행 제목 병합 후 표준품셈 |
| 노임단가 | 1~2행 제목 병합. 2026년 하반기 시중노임 (2026.9.1 적용) |

일위대가 규칙:

- 전선관: 자재 + 전선관부속품비 15% + 잡재료비 2% + 품셈 인부 + 공구손료 3%
- 케이블/전선: 자재 + 잡재료비 2% + 품셈 인부 + 공구손료 3%
- 그 외: 자재 + 품셈 인부 + 공구손료 3%
- 표준품셈에 인부가 여러 명이면 호표에 모두 넣습니다.

## 표준품셈 · 노임단가

프로그램 `data` 폴더의 씨앗 파일이 exe에 같이 실립니다. 처음 산출하면 저장 폴더에 복사본이 생깁니다.

`C:\전기공사_공량산출_결과\데이터베이스\전기_표준품셈.xlsx`  
`C:\전기공사_공량산출_결과\데이터베이스\통신_표준품셈.xlsx`  
`C:\전기공사_공량산출_결과\데이터베이스\노임단가.xlsx`

창에서 **전기**를 누르면 전기 파일만, **통신**을 누르면 통신 파일만 읽습니다. 같은 자재라도 전공·품셈은 파일마다 따로 적습니다. 전기자재의 품셈근거는 통신 파일에서도 `전기 5-1`처럼 둘 수 있습니다.

이 복사본을 고치면 다음 산출부터 반영됩니다. 노임은 대한건설협회 **2026년 하반기 시중노임**을 넣어 두었습니다.

## 실행 (개발 PC)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

테스트:

```bash
python -m pytest
```
